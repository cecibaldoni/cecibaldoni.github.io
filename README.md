# Welcome!
This repo contains the code and resources for my site, which features a range of content from detailed project explorations to artistic illustrations. Here's a brief overview of the main sections:

## Pages
- `index.qmd`: Enter my virtual space through an isometric cityscape, where each building icon opens a new page — About, Illustrations, Open Science, Projects, Talks & Workshops, Publications, Media, Blog, and Contact.
- `content/`: folder with the different pages of my site:
  - `about.qmd`: Learn more about my background and the work I do
  - `project.qmd`: Hub for ongoing and completed projects, linking out to:
    - `shrews.qmd`: My PhD/postdoc research on shrew brain plasticity
    - `talks.qmd`: Conferences, seminars, and workshops
    - `open-science.qmd`: Efforts to improve transparency and reproducibility
    - `games.qmd`: Code & games, mostly built with Quarto
    - `illustrations.qmd`: Science-inspired art
    - `publications.qmd`: My academic (and not) publications
  - `media.qmd`: Press, interviews, and other media appearances
  - `contact.qmd`: How to reach me for collaborations, inquiries, or just to say hi!
  - `privacy.qmd`: Privacy policy (cookies/analytics)
  - `portfolio.qmd`: Standalone portfolio page (no site chrome)
  - `css-scss-scrolly.qmd`: A scroll-through CSS/SCSS beginner's guide, built with Closeread
- `blog/`: My personal blog, where I talk about PKM, coding, and art!
